车载开发专业术语速查手册

2026-05-07 3.9k 字 约 13 分钟

转岗车载 Android（AAOS）初期，面对大量陌生术语难免懵圈。本文整理了车载开发日常高频出现的专业缩写，涵盖硬件、总线、软件架构、UI/UX、开发流程、功能安全等维度，方便随时查阅。

硬件模块

缩写 英文全称 释义
SOC System on Chip 集成 CPU/GPU/NPU 等的主芯片，跑 Android 的核心处理器，如高通 SA8155、联发科 MT8666
MCU Microcontroller Unit 微控制器，负责实时控制整车物理部件，运行裸机或 RTOS，微秒级响应
ECU Electronic Control Unit 电子控制单元，车上某个特定功能的专用计算机，BCM/HVAC/ABS 等都是 ECU 的一种
BCM Body Control Module 车身控制模块，负责车窗、车门、车锁、雨刮、外部灯光（大灯/转向灯）
HVAC Heating, Ventilation & Air Conditioning 空调系统模块，控制温度、风速、出风模式、座椅加热
IP Instrument Panel 仪表盘，显示车速、转速、油量、故障灯、ADAS 提示信息
SWRC Steering Wheel Remote Control 方向盘按键，通过 LIN 总线连接 MCU，控制媒体/通话/语音快捷键
HUD Head-Up Display 抬头显示，将导航/车速等信息投影到风挡玻璃上
OBC On-Board Charger 车载充电机，新能源车管理交流充电的 ECU
EEPROM Electrically Erasable Programmable Read-Only Memory 电可擦可编程只读存储器，按字节擦写，存用户配置、里程、故障码等持久化数据
ADC Analog-to-Digital Converter 模数转换器，将油门踏板/温度传感器等模拟电压转为数字值供 MCU 处理
RTC Real-Time Clock 实时时钟，独立纽扣电池供电，主电源断开后仍走时，保证关机不丢时间

车载总线

缩写 英文全称 释义
CAN Controller Area Network 车载主干总线，广播式报文，速率 125Kbps～1Mbps，用于 BCM/HVAC/IP 等 ECU 互联
LIN Local Interconnect Network 低速总线，主从架构，最高 20Kbps，用于 SWRC 等低频按键节点，成本低
I²C Inter-Integrated Circuit 两线制片内通信总线（SDA + SCL），主从架构，用于 MCU 与板内 EEPROM/传感器通信
SPI Serial Peripheral Interface 四线制高速同步串行总线（MOSI/MISO/SCLK/CS），主从架构，速率可达数十 Mbps，用于板内 Flash、屏幕驱动芯片、高速传感器通信

四总线横向对比

CAN LIN I²C SPI
拓扑 多主广播 主从 主从 主从
速率 ≤1Mbps ≤20Kbps ≤1Mbps 数十 Mbps
线数 2（差分） 1 2 4
距离 跨 ECU 跨 ECU 板内 板内
典型用途 ECU 互联 方向盘按键 EEPROM/传感器 Flash/屏驱

一句话记忆：CAN 是跨 ECU 的高速公路，LIN 是低速节点的胡同，I²C/SPI 都是板内通信——I²C 省线但慢，SPI 多线但快。

软件与系统

缩写 英文全称 释义
AAOS Android Automotive OS Android 车载操作系统，基于 AOSP 扩展，增加 CarService、CarUiLib 等车载组件
AOSP Android Open Source Project Android 开源项目，AAOS 和手机 Android 共同的上游代码库
IVI In-Vehicle Infotainment 车载信息娱乐系统，即中控 Android 主机，是 SysUI 的主要运行环境
HU Head Unit 中控主机，与 IVI 同义，OEM 语境下常用此称呼
RSE Rear Seat Entertainment 后排娱乐屏，AAOS 多屏架构的一部分，有独立 SysUI 实例
VHAL Vehicle Hardware Abstraction Layer 车载 HAL 层，定义所有整车信号的 Property 体系，是 MCU 信号进入 Android 的入口
BSP Board Support Package 板级支持包，芯片厂提供的底层驱动和 HAL，Android 编译必须包含
OTA Over-The-Air 空中升级，通过网络远程更新车机固件，车载 OTA 需通过法规认证
AutoSAR Automotive Open System Architecture 汽车开放系统架构，MCU 软件开发标准框架，分 Application / RTE / BSW / MCAL 四层

UI / UX

缩写 英文全称 释义
HMI Human-Machine Interface 人机交互界面，泛指驾驶员与车辆交互的所有界面，是 SysUI 工程师的主战场
HMI Spec HMI Specification OEM 输出的 UI 设计规范文档，规定每个像素、动画时长、颜色值，SysUI 必须 100% 对齐实现
HUN Heads-Up Notification 车载浮动通知，由 CarHeadsUpNotificationManager 管理，显示在安全独立 window 上
UX Restrictions UX Restrictions 行车 UX 限制，根据车速/驾驶状态动态禁用 UI 操作，违反是车规合规红线
RRO Runtime Resource Overlay 运行时资源覆盖，OEM 定制主题/布局/颜色的主要机制，无需修改源码
CarUiLib Car UI Library AAOS 共享 UI 组件库，提供 CarUiRecyclerView、CarUiToolbar 等，支持 RRO 定制

整车架构

缩写 英文全称 释义
EEA Electrical/Electronic Architecture 整车电子电气架构，定义 ECU 拓扑、总线网络、供电域划分
ADAS Advanced Driver Assistance System 高级驾驶辅助系统，如自适应巡航、车道保持，相关 UI 显示受功能安全约束

开发流程

缩写 英文全称 释义
SOP Start of Production 量产启动节点，整个车载项目的终极 deadline，临近时代码管控极严
CR Change Request 变更申请，SOP-A 后修改代码必须走的流程，需影响分析 + 测试报告 + 多方审批
DVT Design Validation Test 设计验证测试阶段，对应 SOP-B 前后，可自由做特性开发和架构重构
PVT Production Validation Test 量产验证测试阶段，对应 SOP-A，功能冻结，只允许修 bug
HIL Hardware-in-the-Loop 硬件在环测试，用真实 ECU 硬件配合仿真总线做集成测试，比纯软仿真更可靠
ASPICE Automotive SPICE 汽车软件过程改进和能力评估模型，要求需求追溯、测试覆盖等合规流程

功能安全

缩写 英文全称 释义
ASIL Automotive Safety Integrity Level 汽车安全完整性等级，分 QM / A / B / C / D，仪表/ADAS 相关 SysUI 可能涉及 ASIL-B
QM Quality Management 质量管理级，无特殊功能安全要求，中控 SysUI 通常属于此级别
